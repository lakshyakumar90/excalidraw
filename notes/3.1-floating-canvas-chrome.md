# Step 3.1 — Minimalist JojoPen-Style Floating Canvas Chrome

## Summary of Improvements
Overhauled the canvas workspace chrome with floating glassmorphic pills so 90%+ of the viewport stays dedicated to drawing, with presenter viewport following, sync status indicator, preset switcher, zoom dropdown, and keyboard-first shortcuts.

## Key Changes
1. **Top-Right Collaboration Bar (`apps/web/src/components/canvas/FloatingCollabBar.tsx`)**:
   - Active collaborator avatar stack where clicking any avatar toggles **"Follow presenter viewport"** with an active indicator ring.
   - Live sync indicator dot (`Saved` / `Syncing…` / `Offline`).
   - Quick triggers for **AI (`⌘K`)**, **Diagram Code**, **Slides**, **Version History**, **MCP**, **Share**, **Dark/Light Theme Toggle**, and **My Boards**.
2. **Bottom-Left Canvas Controls (`apps/web/src/components/canvas/FloatingBottomControls.tsx`)**:
   - Zoom percentage dropdown (`50%`, `75%`, `100%`, `125%`, `150%`, `200%`, `Fit to screen`), Undo/Redo buttons, and Grid toggle.
3. **Theme-Aware Workspace Container (`apps/web/src/components/canvas/CanvasWorkspace.tsx`)**:
   - Replaced hardcoded `#faf9f6` workspace background with `var(--bg-canvas)` and integrated the floating chrome cleanly without overlapping panels on 1280px or narrow viewports.

## Verification
- Verified TypeScript types cleanly across `apps/web` and responsive floating positioning.
