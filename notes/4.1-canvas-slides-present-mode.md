# Step 4.1 — Canvas "Slides" (Frames + Filmstrip + Presentation Mode)

## Summary of Improvements
Turned infinite canvas frames into an ordered, multiplayer-synced slide deck with a drag-to-reorder filmstrip sidebar and smooth cubic-bezier animated Presentation Mode.

## Key Changes
1. **Slide Ordering Schema (`packages/common/src/element/types.ts`)**:
   - Extended `FrameElement` with optional `title?: string` and `slideOrder?: number`.
2. **Slides Engine (`packages/engine/src/slides/slides.ts`)**:
   - Implemented `extractOrderedSlides(elements)` sorting frames by `slideOrder` with spatial fallback.
   - Implemented `reorderSlides(elements, orderedFrameIds)` bumping `version`/`versionNonce` for normal `applyCommit` multiplayer sync.
   - Implemented `computeSlideViewport(...)` and `animateViewportTransition(...)` using `requestAnimationFrame` cubic-bezier easing.
3. **Slides Filmstrip & Present Mode UI (`apps/web/src/components/canvas/SlidesFilmstrip.tsx`, `PresentModeOverlay.tsx`)**:
   - Built a drag-to-reorder Slides Filmstrip sidebar with slide dimensions, active highlight, "+ Add Slide Frame", and "Present" button.
   - Built fullscreen Present Mode HUD (`Cmd/Ctrl+Shift+P`) with Left/Right/Space/Escape keyboard controls, bottom slide counter, and Laser pointer toggle.

## Verification
- Added `packages/engine/src/slides/slides.test.ts` and verified all Vitest tests pass across `@repo/engine`.
