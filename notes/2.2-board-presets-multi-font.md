# Step 2.2 — 4 JojoPen-Style Board Presets & Multi-Font Engine

## Summary of Improvements
Added 4 curated board visual presets (**Black & White**, **Excali Font**, **Chalk Bold**, and **Clean Sketch**) with bundled web typography, deterministic chalk texture rendering settings, and an atomic restyling helper.

## Key Changes
1. **Multi-Font Loading (`apps/web/src/app/layout.tsx`)**:
   - Bundled `Caveat` (Excali Font), `Architects Daughter` (Chalk Bold), `Plus Jakarta Sans`, `Inter`, and `JetBrains Mono` via `next/font/google` with CSS variables attached to `<html>`.
2. **Board Preset Registry (`packages/common/src/presets.ts`)**:
   - Defined `BoardPresetId` and `BOARD_PRESETS`:
     - `black-and-white`: High-contrast monochrome palette, crisp stroke (`2px`), subtle dot grid.
     - `excali-font`: Warm Excalidraw palette, `Caveat` font, `roughness: 1.2`.
     - `chalk-bold`: Deep chalkboard canvas (`#141A18`), thick chalk strokes (`3.5px`), pastel chalk palette, `Architects Daughter` font.
     - `clean-sketch`: Minimal architectural precision (`roughness: 0.35`, `1.5px`), `Inter` / `JetBrains Mono` typography.
   - Added `applyBoardPresetToElements(elements, presetId)` for single-entry undoable board restyling.
3. **Preset-Aware Sketch Settings (`packages/engine/src/renderer/sketch/settings.ts`)**:
   - Added `sketchSettingsForPreset(presetId, seed)` with deterministic `mulberry32` dual-pass chalk jitter for `chalk-bold`.
4. **Toolbar Switcher (`apps/web/src/components/toolbar/BoardPresetSwitcher.tsx`)**:
   - Added a floating preset switcher pill that listens to `document.fonts.ready` to trigger a clean canvas redraw once fonts load.

## Verification
- Added `packages/engine/src/renderer/presets.test.ts` testing all 4 presets, chalk dual-pass determinism, and element restyling.
- Built `@repo/common` and ran `pnpm --filter @repo/engine exec vitest run`.
