# Step 1.3 — Presigned S3/R2 Image Blobs & Global HTTP Rate Limiting

## Summary of Improvements
Closed the 50 MB JSON DoS surface on `apps/http-server` by introducing presigned S3/Cloudflare R2 image uploads, dropping the Express JSON body limit to `2mb`, and enforcing a Redis sliding-window HTTP rate limiter.

## Key Changes
1. **Presigned S3/R2 Storage Helper (`packages/backend-common/src/storage.ts`)**:
   - Implemented zero-dependency AWS SigV4 presigned `PUT`/`GET` URL generation compatible with AWS S3, Cloudflare R2, and MinIO, with an automatic local-dev fallback when `S3_BUCKET` is unconfigured.
   - Enforced strict MIME validation (`image/png`, `image/jpeg`, `image/webp`, `image/svg+xml`) and a `10 MB` upload size ceiling.
2. **File Presign & Retrieval Routes (`apps/http-server/src/routes/files.ts`)**:
   - Added `POST /api/files/presign` (authenticated, MIME/size validated) and `GET /api/files/:fileId` (302 redirect to presigned S3/R2 GET URL or local dev blob response).
   - Updated `packages/backend-common/src/collaboration.ts` `isValidFile` to accept presigned/object-storage URLs (`https://...` and `/api/files/...`) alongside legacy `data:` URLs.
3. **Web Direct Upload Client (`apps/web/src/lib/api/files.ts`)**:
   - Added `uploadImageViaPresign(blob, dims)` and `getRemoteFileUrl(fileId)` so canvas image uploads stream binary blobs directly to object storage while syncing lightweight `{ fileId, width, height, mimeType }` metadata.
4. **2 MB JSON Limit & Sliding-Window Global Rate Limiter (`apps/http-server/src/app.ts`, `apps/http-server/src/rateLimitMiddleware.ts`)**:
   - Lowered `express.json({ limit: "50mb" })` to `express.json({ limit: "2mb" })`.
   - Added a Redis ZSET Lua sliding-window rate limiter (`120 req/min` globally per IP, `30 req/min` on `/api/auth`), with automatic in-memory fallback and `Retry-After` headers.
