# Step 5.1 — From-Scratch Streamable HTTP MCP Server (`POST /api/mcp`)

## Summary of Improvements
Built a complete, zero-framework Streamable HTTP JSON-RPC 2.0 MCP server inside `apps/http-server` authenticated by scoped `RoomApiToken` credentials, enabling external AI coding agents (Cursor, Claude Code, OpenCode, Codex CLI, AntiGravity CLI) to inspect and draw onto live rooms in real time.

## Key Changes
1. **`RoomApiToken` Schema & Migration (`packages/db/src/prisma/contract.prisma`, `packages/db/migrations/app/20261125_add_room_api_token/migration.sql`)**:
   - Added `RoomApiToken` (`id`, `roomId`, `sceneId`, `tokenHash`, `role`, `expiresAt`, `revokedAt`, `createdById`) with unique hash index and foreign keys.
2. **Scoped Token Management (`apps/http-server/src/routes/mcpTokens.ts`)**:
   - Implemented SHA-256 token hashing, minting (`POST /api/mcp/tokens`), listing (`GET /api/mcp/tokens/:roomId`), and instant revocation (`DELETE /api/mcp/tokens/:tokenId`).
3. **JSON-RPC 2.0 Streamable HTTP MCP Server (`apps/http-server/src/routes/mcp.ts`)**:
   - Implemented `initialize`, `notifications/initialized`, `tools/list`, and `tools/call` authenticated via `Authorization: Bearer <RoomApiToken>`.
   - Wired all mutating tools directly through `CollaborationService.applyCommit` and `RoomRedis.publish` (`room.broadcast` → `elements.committed`) so connected browser tabs receive updates live:
     1. `get_scene_outline`: compact semantic outline of shapes, labels, and arrows.
     2. `create_diagram_from_graph`: server-side zero-overlap layered auto-layout.
     3. `mermaid_to_canvas`: Mermaid syntax → auto-layout canvas elements.
     4. `patch_elements`: element-level create/update/soft-delete patches.
     5. `render_scene_svg`: self-contained SVG snapshot for agent visual self-check.

## Verification
- Added `apps/http-server/src/routes/mcp.test.ts` verifying `initialize`, `tools/list`, `create_diagram_from_graph`, live `elements.committed` broadcast, `render_scene_svg`, and immediate `401` after token revocation.
