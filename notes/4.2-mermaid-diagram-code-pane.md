# Step 4.2 — Live "Diagram Code" Split-Pane Editor (Mermaid/DSL → Canvas)

## Summary of Improvements
Added a collapsible Mermaid/DSL Diagram Code editor backed by a deterministic zero-overlap topological auto-layout converter so users can write or paste architecture diagrams and merge or update them non-destructively on the canvas.

## Key Changes
1. **Mermaid Parser & Auto-Layout Engine (`packages/engine/src/diagram/mermaidParser.ts`)**:
   - Parses Mermaid flowcharts (`graph TD/LR`, `flowchart TD/LR/TB/RL`), `sequenceDiagram`, and `stateDiagram-v2` into structured `{ nodes, edges, errors }` with line-level syntax error hints.
   - Runs layered topological rank assignment + centered layer packing (`layoutGraphToElements`) generating rectangles, diamonds, ellipses, bound text labels, and bound arrows with guaranteed zero overlapping boxes.
   - Added `mergeDiagramElements(existing, generated, "insert" | "replace", diagramGroupId)` for non-destructive insertion and linked-group replacement.
2. **Collapsible Diagram Code Split Pane (`apps/web/src/components/canvas/DiagramCodePane.tsx`)**:
   - Monospace editor with live node/edge count preview, line-level syntax error feedback, **"Insert at viewport"**, and **"Replace linked group"** actions.
