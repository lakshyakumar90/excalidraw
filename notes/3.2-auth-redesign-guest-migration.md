# Step 3.2 — Sign-In / Sign-Up Redesign & Guest-to-Cloud Migration

## Summary of Improvements
Replaced basic auth forms with a split-screen JojoPen-style authentication experience on `/sign-in` and `/sign-up` (while preserving `/login` and `/signup`) and added a non-intrusive guest sync banner for migrating local IndexedDB boards to the cloud.

## Key Changes
1. **Split-Screen Auth Experience (`apps/web/src/components/dashboard/AuthPage.tsx`, `apps/web/src/app/sign-in/page.tsx`, `apps/web/src/app/sign-up/page.tsx`)**:
   - Left column displays a dark interactive SVG architecture sketch preview, product tagline, and board preset badges.
   - Right column wraps `AuthPanel` inside a clean elevated card with dark/light semantic tokens and direct links to switch modes or jump to the canvas.
2. **Guest-to-Cloud Sync Banner (`apps/web/src/components/canvas/GuestSyncBanner.tsx`)**:
   - Displays a dismissible top pill banner when a guest user has unsaved local IndexedDB boards, routing straight to `/sign-in?returnTo=/boards?importGuest=1` to trigger one-click cloud migration via `guestImport`.

## Verification
- Verified `/sign-in`, `/sign-up`, `AuthPage`, and `GuestSyncBanner` compile cleanly with TypeScript.
