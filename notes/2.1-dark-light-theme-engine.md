# Step 2.1 — Full Dark & Light Theme Architecture (Canvas + UI)

## Summary of Improvements
Implemented a first-class Dark Canvas (`#0D1117` / `#111318`, default) alongside Light Mode (`#FFFFFF` / `#F8FAFC`) with deterministic contrast-preserving stroke color adaptation and theme-keyed `OffscreenCanvas` bitmap caching.

## Key Changes
1. **Semantic CSS Variables & Zero-Flash Persistence (`apps/web/src/app/globals.css`, `apps/web/src/app/layout.tsx`, `apps/web/src/lib/theme.ts`)**:
   - Defined `--bg-canvas`, `--bg-surface`, `--bg-elevated`, `--border-subtle`, `--text-primary`, `--text-muted`, and `--accent` for `data-theme="dark"` and `data-theme="light"`.
   - Added a pre-hydration inline theme initializer script in `layout.tsx` reading `localStorage` (`excalidraw:theme`) so there is zero light/dark flash on reload.
   - Added `useCanvasTheme()` hook in `apps/web/src/lib/theme.ts`.
2. **Theme-Aware Renderer & Bitmap Cache (`packages/engine/src/renderer/theme.ts`, `bitmapRendering.ts`, `renderer.ts`)**:
   - Implemented `adaptColorForTheme(hex, theme)` and `adaptElementForTheme(element, theme)` so dark neutral ink (`#111111`, `#000000`) renders crisp off-white (`#F1F5F9`) on dark canvases and white ink flips to `#111827` on light canvases while preserving intentional semantic hues.
   - Added `theme` into `RenderContext`, `StaticRenderOptions`, and `cachedShapeKey(...)` so switching themes immediately invalidates stale `OffscreenCanvas` bitmaps with zero cache ghosts.
   - Updated `drawBackground`, `drawGrid`, and `drawOrigin` to pull from `getCanvasThemePalette(theme)`.
