# Step 5.2 — "Connect MCP" Room Modal & Revoked-Token Verification

## Summary of Improvements
Added a 10-second copy-paste **Connect MCP** modal directly in the top-right collaboration bar so users can mint scoped `RoomApiToken` credentials, revoke them instantaneously, and connect Cursor, Claude Code, OpenCode, Codex CLI, or AntiGravity CLI to any live board.

## Key Changes
1. **Connect MCP Modal (`apps/web/src/components/canvas/ConnectMcpModal.tsx`)**:
   - Mints scoped `RoomApiToken` credentials via `POST /api/mcp/tokens` with role (`editor` / `viewer`) and expiry (`24 hours`, `7 days`, `30 days`) selectors.
   - Displays copy-pasteable configuration snippets for:
     - **Cursor** (`.cursor/mcp.json`)
     - **Claude Code** (`claude mcp add --transport http`)
     - **OpenCode** (`opencode.json`)
     - **Codex CLI** (`~/.codex/config.toml`)
     - **AntiGravity CLI** (`~/.antigravity/mcp.json`)
   - Lists active room tokens with instant **Revoke** (`DELETE /api/mcp/tokens/:tokenId`).
2. **Workspace Integration (`apps/web/src/components/canvas/CanvasWorkspace.tsx`)**:
   - Wired `ConnectMcpModal`, `AiCommandPalette` (`Cmd/Ctrl+K`), `DiagramCodePane`, `VersionHistoryDrawer`, `SlidesFilmstrip`, and `PresentModeOverlay` (`Cmd/Ctrl+Shift+P`) cleanly to the floating collaboration bar and keyboard shortcuts.

## Verification
- Verified revoked token immediately returns HTTP `401` on `POST /api/mcp` in `apps/http-server/src/routes/mcp.test.ts`.
